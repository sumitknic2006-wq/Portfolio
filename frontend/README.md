# Frontend — Sumit Kumar Developer Portfolio

The client application for Sumit Kumar's developer portfolio, engineered with **React 19**, **Vite 6**, and **Tailwind CSS v4**.

## Tech Stack
- **Framework**: React 19 (JavaScript / JSX)
- **Bundler & Tooling**: Vite 6
- **Styling**: Tailwind CSS v4 with custom dark navy palette
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Client Routing**: React Router v7

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```

5. Run linter:
   ```bash
   npm run lint
   ```
